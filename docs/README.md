# PanDocquiles — Documentación Oficial

Esta es la documentación oficial del sistema PanDocquiles.
Irónicamente, esta documentación está diseñada para ser compilada por el propio sistema que documenta (una práctica conocida como *Dogfooding*). 

Si ejecutas el comando `./bin/build.sh` en la raíz del proyecto, esta misma documentación que estás leyendo se transformará mágicamente en un PDF y un HTML profesionales listos para entregarse.
