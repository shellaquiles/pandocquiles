# Política de Seguridad 🛡️

## Reporte de Vulnerabilidades

La seguridad de las herramientas y proyectos de **Shellaquiles** es una prioridad.

Si descubres una vulnerabilidad de seguridad en **PanDocquiles** (por ejemplo, en el manejo de variables de entorno o la comunicación con webhooks):

1. **No abras un issue público** en GitHub.
2. Envía los detalles de la vulnerabilidad de forma privada al equipo de mantenedores.
3. Incluye los pasos detallados para reproducir el fallo.

Agradecemos tu colaboración responsable para mantener el proyecto seguro.
